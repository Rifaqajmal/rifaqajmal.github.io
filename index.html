Client project, United Kingdom · 2026

CBAM Advisory website

The problem
A UK consultancy needed a website that explains the EU and UK Carbon Border Adjustment Mechanism (CBAM) to importers, lets them check whether their goods are in scope, and collects enquiries.
What I built
A custom PHP 8 and MySQL site with an EU CBAM product-scope and importer-threshold checker, validated against 7 test cases, plus an enquiry system and a secure admin dashboard. Protected with CSRF tokens, login throttling, forced password change and email password reset. I also set up DNS, HTTPS, SPF/DMARC email authentication and hosting backups.
Result
Live at cbamadvisory.com since October 2026 and handed over to the client with written user documentation. Built solo in about four weeks.
  • PHP 8
  • MySQL
  • Bootstrap 5
  • JavaScript
  • Chart.js

Personal project

Atmos, a 3D weather app

The problem
Most weather apps show numbers. I wanted one that shows what the sky is actually doing.
What I built
A React 18 and TypeScript app where live OpenWeatherMap data drives real-time 3D scenes with React Three Fiber: rain, snow, thunder, fog and night. It also has hourly and daily forecasts, charts, air quality, city search, favourites and a command palette.
Result
A finished, working app, published with its source code on GitHub.
